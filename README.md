# IT Academy - Sprint 7 - Python

## Descripción

Repositorio correspondiente al Sprint 7 de la especialización en Análisis de Datos de IT Academy, centrado en la creación de funciones, estructuras de datos y bucles con Python.

**Autora:** Laritza Magán

## Contenido

### Nivel 1

- Selección y clasificación de candidatos.
- Segmentación de clientes según el riesgo de abandono de la cesta de compra, identificación de su comportamiento y asignación de mensajes publicitarios de recuperación.

### Nivel 2

- Limpieza, estructuración y clasificación de pacientes según su nivel de riesgo.
- Clasificación de clientes de seguros, cálculo del precio final de sus pólizas y estimación de la probabilidad de fraude.

### Nivel 3

- Generador de contraseñas con NumPy.
- Procesamiento de partidos y creación de una clasificación deportiva con pandas.

## Tecnologías utilizadas

- Python
- NumPy
- pandas
- Google Colab
